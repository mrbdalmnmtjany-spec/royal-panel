# رشق الملكي - Node.js + MongoDB + Socket.IO

## التشغيل
1. ثبّت Node.js وMongoDB.
2. انسخ `.env.example` إلى `.env` وضع بيانات SMTP الحقيقية وسراً قوياً لـ JWT.
3. نفّذ `npm install` ثم `npm run dev`.
4. افتح `http://localhost:3000`.

## المزايا
- تسجيل وإنشاء حساب مع تشفير كلمة المرور.
- إرسال رمز تحقق من 6 أرقام عبر SMTP وحفظ بصمته فقط.
- جلسة JWT داخل Cookie من نوع HttpOnly.
- حفظ العضوية والرصيد بالسنت داخل MongoDB.
- Socket.IO لتحديث الرصيد فورياً.
- Helmet وتحديد معدل طلبات المصادقة.

## مهم قبل النشر
- لا تضع `.env` في Git. استخدم HTTPS واضبط `NODE_ENV=production`.
- الرصيد لا يعدّل من المتصفح. أنشئ لوحة إدارة محمية ومسارات بصلاحيات قبل تفعيل الشحن.
- الاستضافة الثابتة وحدها لا تشغّل Socket.IO أو خادم Node؛ استخدم خدمة تستضيف خادم Node واتصالاً دائماً مع قاعدة MongoDB.
